## Platform

## Product Purpose

CrownCode is Hasan Arthur Altuntaş's showroom for independent software projects. Visitors should understand a project's purpose and open its working page or source repository. The music portfolio is a related destination.

## Capabilities and Constraints

The existing Next.js Pages Router application contains eight projects in `config/product-catalog.ts`. This catalog owns routes and localized product data. Project status must remain truthful; research projects must not be presented as validated production services. Preserve the shared header, footer, project routes, and Turkish/English support.

## Brand Commitments

The user explicitly requires the existing warm dark palette, crowned-face logo, mobile responsiveness, natural copy, and a continuous cinematic scroll experience. The homepage should feel like a showroom, with authored images instead of generic cards. The rejected planet diagram is an anti-reference. Design decisions are delegated by the user in the task conversation.

## Evidence on Hand

`public/logo-main.png` is the supplied brand mark. `public/images/noir-grain/` contains actual project screenshots. `public/images/auris/` contains existing project artwork. New generated studio imagery is conceptual brand artwork, not photography of a real product or place.
